# Valid.it

> Valid.it (Validit.ai) is an AI-based fraud prevention SaaS that lets organizations validate users' statements remotely and in real time through a standard smartphone, laptop, or tablet camera. Its patented physio-behavioral AI combines computer vision, signal processing, and PPG bio-signal analytics to detect deepfakes, synthetic identities, and deceptive intent — delivered as a standalone web-based solution or via API integration. A Techstars portfolio company.

Valid.it publishes no public developer portal, API reference, or OpenAPI specification. The FAQ documents API integration for onboarding flows, KYC/AML processes, insurance claim verification, HR candidate screening workflows, case-management systems, and government and security platforms; integration details require contacting the company (office@validit.ai). A production API host exists at api.validit.ai (structured JSON error envelope) but exposes no public spec or docs.
