# Valid.it

Valid.it (Validit.ai) is an AI-based fraud prevention SaaS that lets enterprises, governments, and financial institutions validate users' statements remotely and in real time through a standard smartphone, laptop, or tablet camera. Its patented physio-behavioral AI combines computer vision, signal processing, and PPG bio-signal analytics to detect deepfakes, synthetic identities, and deceptive intent across onboarding, KYC/AML, insurance claim verification, security vetting, and HR screening — delivered as a standalone web-based solution or via API integration.

Valid.it publishes no public developer portal, API reference, or OpenAPI specification; API integration is offered but details require contacting the company. A production API host exists at api.validit.ai.
